Six-person team, and it's live, not a prototype.

**Agent tooling:** I write skills for coding agents — [youtube-playlist-skill](https://github.com/smarpitm/youtube-playlist-skill) turns any topic into a real public YouTube playlist, for Cline and Codebuff.

## How my team runs

Our SIH sprint ran on a workflow I set up: a frozen contract file everyone reads before touching code, per-person prompt books so each member's agent knew exactly what it owned, and humans reviewing every merge. Shipped in days what normally takes weeks. I like building the workflow as much as the product.
